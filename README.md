> **AI-Powered Personalized and Inclusive Learning Platform**

HexnicAI is an AI-powered learning ecosystem designed to help students study more efficiently through **personalized learning tools, accessibility-focused utilities, AI assistance, and organized academic resources**.

Together with **C-WATS**, HexnicAI brings AI-powered learning assistance and subject-specific academic resources into a connected student ecosystem.

---

# 🌐 Overview

The HexnicAI ecosystem consists of two complementary platforms:

### 🤖 HexnicAI — AI-Powered Learning Tools

An intelligent learning platform focused on personalization, accessibility, and AI-assisted education.

Current tools include:

- 📚 **StudyAI** — AI-powered study schedule generation
- 🗣️ **Speak Easy** — Accessibility and inclusive learning tools
- 🧠 **FocusAI** — AI-powered learning assistant
- 💻 **C Program Master** — Interactive C programming learning environment

### 🎓 C-WATS — Community Academic Ecosystem

A dedicated ecosystem of independent subject-specific academic platforms.

Current academic modules include:

- **IT-Workshop** — VIVA & LAB examination preparation
- **KTU Discrete Mathematics** — Discrete mathematics study resources
- **CImp** — C programming theory and practical programs
- **EEIPR** — Engineering, Entrepreneurship & Intellectual Property Rights
- **FOCFHWTWD** — Foundations of Computing and Web Design
- **DigiDes** — Digital Electronics & Logic Design

# 🚀 Key Features

## 🤖 AI-Powered Learning

- Intelligent study schedule generation
- Personalized learning assistance
- AI-powered study recommendations
- Progress tracking and analytics
- Interactive AI learning tools

## ♿ Accessibility & Inclusive Learning

HexnicAI is designed with accessibility and inclusive learning in mind.

Features include:

- Text-to-speech functionality
- Speech recognition support
- Dyslexia-friendly reading options
- Customizable fonts
- Customizable colors and reading modes
- Keyboard navigation
- Screen-reader-friendly interfaces
- Accessibility-oriented learning utilities

## 📚 Organized Academic Resources

Through the C-WATS ecosystem, students can access:

- Subject-specific study materials
- Question banks
- Practice problems
- Laboratory preparation resources
- Viva questions
- Solved model papers
- Programming resources
- Interactive engineering tools

# 📦 Prerequisites

Before running the project, install:

- Node.js **18 or later**
- npm, yarn, or pnpm

Verify your installation:

```bash
node -v
npm -v
```

---

# 🚀 Installation

### 1. Clone the repository

```bash
git clone https://github.com/ATS-001/HexnicAI.git
```

### 2. Navigate into the project

```bash
cd HexnicAI
```

### 3. Install dependencies

```bash
npm install
```

or

```bash
yarn install
```

or

```bash
pnpm install
```

---

# ▶️ Running the Development Server

Start the development server:

```bash
npm run dev
```

Open your browser and visit:

```text
http://localhost:3000
```

---

# 📦 Production Build

Create a production build:

```bash
npm run build
```

Start the production server:

```bash
npm start
```
