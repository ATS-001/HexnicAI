# HexnicAI

> **AI-Powered Personalized and Inclusive Learning Platform**

HexnicAI is a comprehensive learning ecosystem designed to help students manage their studies efficiently through intelligent AI tools and accessible learning resources. Combined with C-WATS, it provides both AI-powered learning assistance and organized academic resources.

---

## Overview

HexnicAI consists of two integrated platforms:

### **HexnicAI** – AI-Powered Learning Tools
An intelligent learning platform that uses AI to personalize the study experience:
- **StudyAI** – AI-driven study schedule generation
- **Speak Easy** – Accessibility tools for inclusive learning
- **FocusAI** – AI-powered learning assistant
- **C Program Master** – Interactive C programming learning environment

### **C-WATS** – Community Academic Ecosystem
A dedicated ecosystem of independent subject-based learning modules:
- **IT-Workshop** – VIVA & LAB exam questions for BTECH CSE
- **KTU Discrete Math** – Discrete mathematics study materials
- **CImp** – C program theory and implementation practice
- **EEIPR** – Engineering, Entrepreneurship and IP Rights resources
- **DigiDes** – Digital design resources and learning materials

---

## Key Features

### AI-Powered Learning
- Intelligent study schedule generation based on subject difficulty
- Personalized learning recommendations
- Progress tracking and analytics
- AI-powered study assistance

### Accessibility & Inclusivity
- Text-to-speech functionality for better accessibility
- Dyslexia-friendly reading modes and formatting
- Speech recognition support for hands-free interaction
- Customizable fonts, colors, and reading modes
- Keyboard navigation and screen reader support
- Support for students with learning disabilities

### Organized Academic Resources
- Subject-specific learning materials
- Question banks and practice problems
- Practical coding and design resources
- Comprehensive study guides

## Quick Start

### Prerequisites
- Node.js 18+ 
- npm, yarn, or pnpm

### Installation

```bash
# Clone the repository
git clone https://github.com/ATS-001/HexnicAI.git
cd HexnicAI

# Install dependencies
npm install
# or
yarn install
# or
pnpm install
```

### Development

```bash
npm run dev
# or
yarn dev
# or
pnpm dev
```

Open [http://localhost:3000](http://localhost:3000) to view the application.

### Production Build

```bash
npm run build
npm start
```

## Technology Stack

- **Frontend**: Next.js 16, React 19, TypeScript

- **Animations**: Custom React and CSS animations, Brownian motion canvas background
- **Architecture**: Server Components, Client Components, API Routes
- **Deployment**: Vercel
